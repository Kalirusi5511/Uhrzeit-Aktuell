❓ Hilfe & Anleitung

1. Die Uhr:
Die Uhr zeigt automatisch die aktuelle Zeit und das Datum deines Geräts an.

2. Einstellungen öffnen:
Klicke auf das ⚙ (Zahnrad) oder die drei Punkte ☰ oben rechts.

3. Datumsformat ändern:
Im Menü findest du eine Tabelle. Klicke auf den gelben B-Button oder drücke die Taste B auf deiner Tastatur, um das Format zu wechseln.

4. Geheimer PIN-Schutz:
Klicke im Menü 3-mal schnell auf den Titel "Datum & Uhrzeit". Es erscheint ein gelbes Feld, wo du eine PIN und einen Discord-Webhook eingeben kannst.

5. PIN vergessen?
Wenn du gesperrt bist, klicke auf "PIN vergessen?". Der Code wird an deinen Discord gesendet (falls eingerichtet) oder als Popup angezeigt.
